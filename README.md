# 🛍️ React Shoe Shopping Cart

A simple shopping cart built with **React.js, JavaScript, and Tailwind CSS**.

### ✨ Features
- Display shoe products with images and prices.
- Add products to the cart.
- Increase or decrease product quantities.
- Automatically calculate the total price.
- Remove products when quantity reaches zero.
- Dynamic UI updates using React state.

### 🛠️ Technologies
- React.js
- JavaScript (ES6+)
- Tailwind CSS
- HTML5 & CSS3

### 🚀 Getting Started

```bash
npm install
npm run dev
```

### 📚 Concepts Practiced
- `useState` for state management
- `map()`, `filter()`, `find()`, and `reduce()`
- Spread operator (`...`)
- Event handling and conditional rendering

**Built with ❤️ while learning React.**
